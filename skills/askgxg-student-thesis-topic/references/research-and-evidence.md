# 研究与资料核验

## 资料顺序

商业新闻负责告诉你“什么值得留意”，不能独自承担关键事实。确认公司、数字和业务说明时，优先顺序如下：

1. 交易所、监管机构、公司法定年报、招股书和业绩公告；
2. 公司正式新闻稿、业绩材料、监管和行业统计资料；
3. 可信财经媒体和研究报道，用于发现问题和交叉定位；
4. 论坛、短视频、二手转载，只能作为线索。

关键事实至少留下报告名称、期间、页码或章节/稳定链接。新闻还要记录新闻发布时间与事件发生时间，避免把转发日期当作事件日期。

## 四种内容要分开

| 内容 | 怎样处理 |
| --- | --- |
| 报告直接披露的收入、门店数、毛利率、业务说明 | 可以作为事实引用 |
| 管理层对变化原因的说明 | 写成“公司解释为……” |
| 依据原始数做出的增长率、占比、差额 | 写清计算口径和期间 |
| 根据数据提出的可能解释 | 写成研究问题或解释方向，不能写成事实 |

## 形成候选题前的最小核验

对每个准备展示给同学的方向，至少确认：

- 公司身份、主营业务和相关报告期间；
- 一个可复核的经营变化或披露差异；
- 能获得的核心资料；
- 课程任务是否能容纳这个范围。

同学指定公司资料不够时，说明缺在哪里，再建议缩到已经披露的部分，或者提供资料更完整的可比案例。不要用搜索结果摘要替代原始披露。

## 从事实到选题

按“变化—问题—专业知识—资料—基本分析—求职讨论”走。

例如，一家公司披露海外收入增长，可以形成“海外收入增长与毛利率变化是否同步”的观察；需要年报分部资料、收入和成本数据，再结合公司对地区业务的说明。它可以训练财务分析同学阅读分部数据、比较结构变化和解释经营差异。不能在没有资料时先断言海外扩张提高或拉低了利润。

## 候选之间怎样取舍

优先选择范围更清楚、资料更足、核心数字可回查、变化更具体、能够解释而非只罗列指标的题目。题目相近时保留范围更小、资料更可靠的一项；不要用三个标题重复讲同一件事。

近期新闻没有后续结果数据时，缩到企业已经披露的计划、投入、定价、渠道或结构变化。需要验证经营效果的题目，明确下一份报告或哪类数据出来后才能继续判断。
